and rejected alternatives without changing the counters or frontier.

**Goal.** Carry the checked rights basis and decision digest into admission
results, manifest rows and release identity, and rebuild all current specimens.

**Entry.** The pushed Step 1 branch and its committed specification, with the
selected design unchanged.

**Exit.** Every current source row retains its basis and decision digest; build and
verify refuse missing or malformed rights metadata; all three releases and
their projections agree with the six-field identity. This command must pass:

```sh
python3 scripts/run_checks.py --base fiat/1364-bind-retained-source-rights-into-release-id --scope root --scope anamnesis --format json
```

**Files.** Change `plugins/anamnesis/skills/anamnesis/scripts/anamnesis.py`
and `plugins/anamnesis/skills/anamnesis/schemas/release-v1.json`.
Add `plugins/anamnesis/tests/test_s2_source_rights.py`; update existing
source-row, identity and projection assertions in the plugin tests.
Regenerate current `release/manifest.json` and `projections/` under the
`pilot`, `estate` and `synopsis` specimens. Update current demonstration
program digests and identity-bearing data through their owning generator when
the executable changes. Update current documentation that otherwise makes the
tree's tests false. Preserve historical ADRs, audit records, ledger rows and
`docs/kickoff/1359/evidence/consumer-inputs.json` unchanged.
Update the package to 0.3.2 and regenerate required installation and Horos files.

**Tests.** Calculate `rights_sha256` independently from the canonical checked
rights object; changing basis, holder, statement or disclosure must change the
release ID. Require named refusal for absent, unknown, wrong-type or malformed
basis, disclosure and rights digest, embargoed rows, and digest-only/public

Mutating each identity-bearing field without changing the ID must refuse.
Restricted sources remain withheld with their denominator counted; holder and
statement text enter no release component or projection. Compare all five graph
components and both input policies against the starting commit for each corpus.
Keep all existing tests green and preserve their original assertions where
they test historical behaviour by using explicitly historical fixtures.
Run the new mutation assertions against the parent implementation and retain

Elenchus command: `python3 plugins/anamnesis/tests/elenchus.py --step 2 {report}`; format: `unittest-json-v1`; report file: `.hexaemeron/elenchus-step-2.json`.

**Disciplines.** phylax: untrusted manifest fields must refuse before formatting
or membership checks can raise. ephoros: preserve named refusal codes and
source identities without decision prose. metron: no speed claim or new budget.
elenchus: use mutation guards for missing binding and each discovered failure.
hypomnema: explain the stricter source-row compatibility at its reader and in
