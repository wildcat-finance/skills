# Anamnesis evolution ledger

Policy: [../../../hexaemeron/skills/VERSIONING.md](../../../hexaemeron/skills/VERSIONING.md)

- Current version: `anamnesis-v4.1.0`
- Frontier status: `open`
- Frontier revision: `declared-scope`
- Current frontier: What a corpus preserves is declared in the curation policy the release manifest records and the release id hashes: an id, one sentence, the admitted source ids and the record bounds. Two corpora ship under their own scopes, and neither builds under the other's.
- Next Fiat job: Make the declared mapper select the implementation that reads a source. The curation policy declares a mapper name and version, the resolver always runs `warden-audit-round-markdown`, and every assertion records the declared name, so a policy naming a mapper that does not exist still produces a release whose assertions attest that mapper. Accepted when an unknown mapper refuses at curation rather than being recorded, and a source in a second producer's format is admitted under a mapper the policy selects, with the release naming the mapper that actually read it.
