- **The rule.** Only `remote_branch_tip(..., native_relation=True)` changes. It reads the caller's `credential.*` configuration once with the caller's own Git and every repository-selecting `GIT_*` variable removed, drops command scope, parses the result strictly under the study's caps, and replays the entries in command scope after one empty `credential.helper` reset.
