## Step 3: Capture a bounded local Berean release

**Goal.** Add `capture-grounded-agent`, a dependency-closed local adapter that reads an existing `berean-release/v1` tree, binds its exact evidence into grounded-agent/v1, and writes only a self-verifying statement.

**Entry.** Step 2's exit state, with the public predicate contract and conformance corpus green but no capture command.

**Exit.** The adapter accepts a release root, reader-visible name, producer tool/version/argv, optional previous grounded-agent statement, explicit first-capture reason when previous is absent, and output path. It uses no Berean import, subprocess, model, network, or mutation. It reads bounded regular files through confined portable paths; rejects symlinks, special files, duplicate JSON keys, excessive depth/size/count, changing bytes, undeclared files under the release boundary, and output aliases into that boundary. It independently checks the closed `berean-release/v1` fields, canonical semantic `release_digest`, corpus manifest and corpus file digests, reads/answer/evaluation digests, and the optional promotion chain's closed shape, order, release relation, and declared evaluation digests. It projects promotion bytes and terminal action/target only; the raw subject preserves the producer's evaluation evidence while the predicate carries no forbidden result or threshold keys and makes no complete Berean-verification claim. Explicitly absent reads, evaluations, or promotion chain remain `null` with bounded reasons. It normalises and de-duplicates subject names, constructs the comparison, self-verifies all Ariadne gates/checks in memory, and atomically replaces a caller-approved output only after success. A capture over `plugins/berean/examples/goldfinch-demo-v0/release` verifies offline; tampered release identity, corpus, reads, answer, evaluation, promotion, path, and output cases fail closed without a final statement.
