# Checkpoint network sandbox evidence

This directory preserves the study, two-step runbook and design selection for
[issue #1794](https://github.com/wildcat-finance/skills/issues/1794).
`bubblewrap-seccomp` passed the measured selection gates; a network namespace
alone allowed loopback and failed them. The release guide at
`docs/checkpoint-authority/release.md` owns installation, supported profiles,
refusals and the real conformance command.

The study and runbook are exact controller-receipted copies. The design record
and ten selection reports are unchanged evidence from the pre-implementation
comparison at `66f52785813a8453e7c7d54f2371aa8f6e465640`. The two research
constructions called the unchanged bounded runner and pinned cosign through an
in-memory experimental boundary. These measurements do not establish product
conformance or a macOS result.

`research/provenance.json` maps each public research copy to its original
run-local path and SHA-256. The copies include the executed comparison source,
raw observations, report projection, package identity, filter and supporting
stdin/device/limit experiments. They contain public synthetic fixtures and
local host observations, not service checkpoints or credentials. The recorded
commands expect those original research paths and the exact pinned tools;
reproduction belongs in a separate checkout of the recorded base. The source's
cosign path records the temporary tool installation used for that measurement.
New measurements have their own evidence; never replace the accepted reports.

The local product and hostile criteria must pass before Step 2 opens. Actual
hosted Ubuntu 24.04 x86_64 and macOS 15 arm64 evidence must pass before
integration. A unit fixture or a report's shape cannot supply either execution.
