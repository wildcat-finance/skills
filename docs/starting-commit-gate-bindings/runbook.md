## Operating boundaries

- **The rule.** When the running controller's pin refuses a registered module, Fiat reads that module's blob and the Protasis adapter blob at the run's recorded starting commit through bounded Git. It takes the historical module pins from the adapter blob by parsing one assignment as data, never by importing it. It admits a module only when the worktree bytes equal the base blob and the module's AST digest equals the base pin. Replay admits a receipt's adapter digest only when it equals the digest of the base adapter blob or a reviewed digest. Every other field of a receipt must still equal current validation. The adapter stays inert: it receives what the caller derived and reads no Git.
- **Always.** Run the owning root and Hexaemeron suites before each commit and pass the exact staged tree through the commit gate; sign every commit with author and committer Dr Laurence E. Day and check GitHub verification at each step's first commit; run Imprimatur and Brevitas on shipped prose and Phylax, Ephoros and Hypomnema on changed code and documents; keep every refusal ahead of any state, ledger or artefact write; run Sapheneia, Imprimatur, Vulgate and a final Imprimatur on new prose; archive each pushed step through the checkpoint command.
- **Ask first.** Changing a receipt schema, a ledger event or the init marker; widening the reviewed adapter list beyond the rule above; changing the closed `protasis-gate-commands/v1` result shape; touching CI; adding a dependency.
- **Never.** Edit a run's state or ledger by hand; port an unrelated Hexaemeron script into any run's product tree; drive one run with two controllers after a supersession is recorded; edit `protasis.py`, `ephoros.py`, `hypomnema.py`, `phylax.py`, `scripts/run_checks.py` or `plugins/hexaemeron/tests/run_tests.py`, whose registered modules this run's own gate receipt binds; edit `plugins/hexaemeron/tests/test_hexctl.py`, which sits at the read ceiling; commit anything under `.hexaemeron/design/fixtures/` or `.hexaemeron/design/evidence/`, which carry local paths and another run's state; edit an audit record or a numbered decision record; delete a failing test; claim a command ran when it did not; merge a step into `main`.
