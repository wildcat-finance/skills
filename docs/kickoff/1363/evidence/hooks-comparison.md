# Hooks and factory comparison

Independent source reads cover 10 deployed files and 15 candidate files, including both full `HooksConfig.sol` libraries. The concrete runtime partitions reconcile exactly to **70 deployed actions and 120 candidate actions**. `IHooks.sol` contributes its implemented factory-only callback; interface declarations and library dispatch are excluded from the runtime denominator.

“Deployed” names the comparison role. These records do not establish a match to every mainnet runtime. Each action uses `Contract:canonicalSignature` and records source/body hashes, selector, effective caller checks, helper calls, state effects, value flow and conditional events. Constructors are separate from runtime actions. No scoped inheritance chain adds Ownable actions; factory inheritance adds `changeSphereXEngine`.

The union contains **52 added, 2 removed, 55 changed and 13 locally unchanged** action IDs. The JSON `semantic_comparison` rows give the reason and sources for every ID. Local equivalence excludes effects inside external providers, markets, tokens, factories and SphereX engines.

The source-derived call graph resolves an abstract helper against each concrete runtime before filtering for implemented bodies. All 25 deployed and 47 candidate inherited action rows were audited; the five `onCreateMarket` rows now include their concrete creation writes and events, and no reachable abstract internal endpoint remains unresolved. Declared and resolved targets, C3 order, call arguments and source locations are preserved in `extraction_basis` and each action call edge.

Successful queue callbacks can persist a credential-granted log, but cannot mark the account as a known lender or persist a credential-revoked log: `_tryValidateAccess` passes `canSetKnownLender=false`, and failed credential checks revert the outer callback. Those impossible event paths are recorded separately in `excluded_event_paths`. See [deployed helper](https://github.com/wildcat-finance/v2-protocol/blob/f5a26146987926f4811b72a795d662813dedfe85/src/access/BaseAccessControls.sol#L712) and [candidate helper](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/access/BaseAccessControls.sol#L940).

FixedTerm queue callbacks require the stored maturity even if the supplied state says closed; that argument is ignored. Periodic queues apply their time gate when the supplied state is open, with start-inclusive and end-exclusive windows; the helper also accepts an already-closed stored market. See [deployed FixedTerm](https://github.com/wildcat-finance/v2-protocol/blob/f5a26146987926f4811b72a795d662813dedfe85/src/access/FixedTermHooks.sol#L306), [candidate FixedTerm](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/access/FixedTermHooks.sol#L371), [Periodic queue](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/access/PeriodicTermHooks.sol#L580), and [window helper](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/access/PeriodicTermHooks.sol#L476).

The periodic APR override also excludes the inherited temporary-reserve events: it returns through proposal execution for every decrease, and reaches the parent only for equal or higher APR. The inherited map starts empty and has no other writer, so the activation branch cannot be reached in this concrete runtime. See [override branches](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/access/PeriodicTermHooks.sol#L779) and [parent write](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/access/MarketConstraintHooks.sol#L278).

The dispatch libraries send zero ETH, copy a caller-controlled suffix into hooks data and bubble callback reverts. `onTransfer` passes the original market caller separately from `from` and `to`. APR callback return decoding requires 64 bytes and masks both results to `uint16`. Candidate bit 84 enables the periodic execution capability, but its market-side dispatch is outside this file. See [candidate shared call](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/types/HooksConfig.sol#L96), [transfer calldata](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/types/HooksConfig.sol#L497), [APR return](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/types/HooksConfig.sol#L820), and [periodic flag](https://github.com/wildcat-finance/v2-protocol/blob/bea503c2736d47de7fd34130c64f10783dc35b39/src/types/HooksConfig.sol#L291).

Direct deltas stay with the function body that writes them; helper-call evidence is separate. The JSON `invariant_candidates` field records each claim with its write sites and boundaries. No token-balance conservation or economic relation is inferred from this configuration subsystem. Source paths and event possibilities were checked without executing a callback ABI harness or independently reproducing runtime traces.
