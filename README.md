# THE SHOGGOTH

The Shoggoth is a collective of small, specialised agents for crypto research
and development, distributed as **Wildcat Labs Skills**. They preserve
evidence, investigate protocols, build and test software, review contracts,
measure changes, and hand work on without turning uncertainty into fact.

It is not one general assistant with a cast list. Each member owns a bounded
job, says what it checked, shows the evidence behind the result, and stops
where another specialist or a person has to take over. There
are <!-- front-door:count key="governed" -->27 governed skills
in <!-- front-door:count key="plugins" -->18 plugins here, and both numbers
are derived from the tree each time this page is checked.

## WHAT CAN IT DO?

The members below rebuild something real, offline, from records preserved in
this repository. Each card binds its skill, its claim and the digest of the
demonstration ledger beside that skill. Downgrading, editing or removing that
record fails the check rather than quietly leaving the claim standing. Each
command writes a report to a path that must not already exist.

## HOW TO INSTALL IT

Install the dependency-closed router through the Agent Skills convention:

```bash
npx skills add wildcat-finance/skills-runtime --skill promise-machine
```

That package is generated from this repository and published hourly to
[wildcat-finance/skills-runtime](https://github.com/wildcat-finance/skills-runtime),
so an install can sit up to an hour behind `main`. The [installation
guide](./INSTALL.md#local-agents) covers the non-interactive Codex command,
private organisation distribution, and the first-party licence boundary.

## WHAT A RESULT MEANS

The [Promise Machine contract](./PROMISE_MACHINE.md) is the shared law between
first-party skills. State what a successful operation establishes. Name the
evidence behind it. Carry the caveats forward when another skill consumes the
result. Refuse the dependent action when the evidence is missing or stale, and
leave inspection, repair, rerun and rollback available. It checks those
relationships and the repository's structure; it does not certify that a domain
claim is true.

## WHAT IT RUNS ON

[`pyproject.toml`](./pyproject.toml) declares the supported Python minor, and
[`.python-version`](./.python-version) pins the exact interpreter every
Python-backed skill and repository check uses.
[ADR-038](./docs/decisions/ADR-038-pin-the-python-suite-to-one-interpreter.md)
records the one-interpreter rule and
[ADR-042](./docs/decisions/ADR-042-advance-the-python-suite-to-3-14.md) the
current transition. Member pages list the rest: Git, GitHub CLI, Foundry, a
Solidity compiler or container runtime, and an archive Ethereum endpoint are
the common ones. Verification and replay are often offline even where capture
is not. [AGENTS.md](./AGENTS.md) is the file an agent runtime reads.

## IDENTITY AND AUTHORITY

"Shoggoth" may mean the member currently speaking or the collective as a whole;
context decides which. The [identity contract](./SHOGGOTH.md) records the exact
addressing, portrait, authorship and host-provenance rules. A name never
activates a skill or widens anyone's authority.
