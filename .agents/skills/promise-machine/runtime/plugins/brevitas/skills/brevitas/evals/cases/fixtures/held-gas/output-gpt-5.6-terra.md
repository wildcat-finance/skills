`takeWithQueue` necessarily allocates a memory array sized to `claimCount`, then performs one external `claimAt` call and one memory struct write per claim. Its cost therefore grows linearly with queue length; at a sufficiently large length it can exhaust gas and revert, as explicitly documented.
