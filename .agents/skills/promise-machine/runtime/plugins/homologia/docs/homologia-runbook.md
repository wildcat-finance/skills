# Runbook: Homologia, numeric agreement between on-chain computations and their off-chain mirrors

Derived from the attached Homologia study. The chosen design is option A: a standalone plugin whose chain side is evidence-classed expected answers, whose mirror side is a pinned subprocess adapter, and whose verdicts recompute byte for byte from their declared inputs. Five steps, dependency order, one pull request each. No implementation starts until the issue owner approves the study's assumptions, including the name, the no-EVM posture and any new CI surface.

**Goal.** Add the standalone plugin with its contracts, packaging, study, runbook and a green command stub.
**Entry.** `main` at `81105bb`, in the run worktree the controller created before preflight. The task issue is bound: [skills#458](https://github.com/wildcat-finance/skills/issues/458). CI changes require the issue owner's explicit approval.
**Exit.** The plugin, both host manifests, portable route, marketplace entries, runtime contract, canonical `SKILL.md`, `EVOLUTION.md`, licence, study, runbook, ADR-001 and a `homologia.py --help` stub are present; `python3 -m unittest discover -s plugins/homologia/tests -t plugins/homologia`, `python3 -m unittest discover -s tests`, `python3 scripts/promise_machine.py check`, and `python3 scripts/promise_machine.py coverage --check` exit 0; the new plugin is discovered rather than added through a hand-maintained universe.

## Step 2: Validate manifests, vectors and expected-answer provenance

**Goal.** Turn one declared manifest, its vector sets and their evidence-classed expected answers into checked, cap-bounded inputs without executing anything.
**Entry.** Step 1's green exit.
**Exit.** `homologia.py check` validates pair identity (chain, contract, function identity, mirror revision), vector schema, scale identities on every vector set against the declared mirror scale, provenance class on every expected answer with `proved` accepted only alongside its Lazarus artefact reference, tolerance declarations, path form and every input cap, then writes a checked-inputs record atomically; `python3 -m unittest plugins.homologia.tests.test_check` passes; the example manifest produces the expected checked-inputs digest twice; root, plugin, Promise Machine, Phylax and Ephoros checks exit 0.
**Files.** `plugins/homologia/scripts/homologia.py`, `plugins/homologia/references/manifest-v1.schema.json`, `plugins/homologia/references/vectors-v1.schema.json`, `plugins/homologia/tests/test_check.py`, manifest and vector fixtures under `plugins/homologia/tests/fixtures/`, `plugins/homologia/docs/schema-compatibility.md`, and `plugins/homologia/docs/decisions/ADR-002-chain-answers-are-evidence.md`.
**Tests.** Positive fixtures cover a proved set with its Lazarus reference, a recorded set with chain and block identity, an asserted set with a named author, and a declared tolerance. Negative fixtures cover a bare `proved` label without its artefact reference, a missing or unequal scale identity, an unknown provenance class, an undeclared or duplicate vector file, an absolute path, per-file and aggregate cap breaches, a malformed vector, a tolerance without a declaration, and partial output after refusal. Expected minimum: 20 new cases.
**Disciplines.** phylax: this step opens the untrusted manifest and vector boundary; bounded single-descriptor reads, repository-relative paths, schema checks before field access and atomic output close it. ephoros: stable refusal codes and the checked-inputs record answer why a CI invocation stopped. metron: none until the scale fixture exists. elenchus: each schema, provenance and cap refusal is captured red before its guard. hypomnema: ADR-002 lands because the evidence-in posture becomes real here.

## Step 3: Execute mirrors through the adapter protocol

**Goal.** Run one declared mirror over checked vectors as a pinned, bounded subprocess and record its answers and runtime identity without judging them.
**Entry.** Step 2's checked-inputs record and schemas, green.
**Exit.** `homologia.py run-mirror` launches the pinned argv with no shell, a minimal child environment carrying no output path, vectors as JSONL on stdin and answers read bounded from stdout; it refuses a non-integer answer, an answer-count or order mismatch, a timeout or an output-cap breach, and records the mirror's runtime identity and answer digest atomically; the reference Python adapter round-trips the example vectors; `python3 -m unittest plugins.homologia.tests.test_run_mirror` passes and all step-2 gates remain green.
**Files.** mirror-execution code in `plugins/homologia/scripts/homologia.py`, `plugins/homologia/references/adapter-protocol.md`, `plugins/homologia/adapters/mirror_adapter.py` (reference Python adapter), `plugins/homologia/tests/test_run_mirror.py`, adapter fixtures including a hostile fake mirror, and `plugins/homologia/docs/decisions/ADR-003-subprocess-adapter-protocol.md`.
**Tests.** Positive fixtures cover an exact round trip, a large vector set streamed within caps, and runtime-identity recording. Negative fixtures, driven by a hostile fake mirror, cover a float-formatted answer, an exponent form, a locale separator, fewer answers than vectors, extra answers, out-of-order flushing, an infinite-output flood stopped by the cap, a hang stopped by the timeout, a nonzero exit with valid-looking output, and an attempt to read an inherited output path. Expected minimum: 18 new cases.
**Disciplines.** phylax: this step opens the deliberate subprocess boundary; pinned argv, no shell, minimal environment, bounded pipes and the timeout close it. ephoros: recorded runtime identity and per-refusal codes make an unattended failure diagnosable. metron: none, no performance claim yet. elenchus: every hostile-mirror behaviour is a red guard before its handler. hypomnema: ADR-003 fixes the adapter protocol, the public interface this plugin must hold stable.

## Step 4: Compare, render and verify the verdict

**Goal.** Produce the parity verdict, divergence specimens and report from checked inputs and recorded mirror answers, then verify all artefacts together by recomputation.
**Entry.** Step 3's recorded answers and runtime identities, green.
**Exit.** `homologia.py compare` judges exact integer equality by default, applies a tolerance only where declared and echoes it in the verdict, stamps the weakest provenance class used, and preserves every divergent vector with both answers and the signed difference as a specimen; `render` uses fixed templates and cannot introduce a number, vector, provenance class or correctness verb absent from the verdict; `verify` recomputes verdict, specimens and report bytes from the manifest and recorded answers and exits nonzero on any digest difference; the committed wad-interest example agrees exactly and the seeded floor-versus-half-up example produces its divergence verdict; `python3 -m unittest plugins.homologia.tests.test_compare plugins.homologia.tests.test_render plugins.homologia.tests.test_verify` passes; Imprimatur and Brevitas accept the example report; all earlier gates stay green.
**Files.** comparison, render and verify code in `plugins/homologia/scripts/homologia.py`, `plugins/homologia/references/verdict-v1.schema.json`, `plugins/homologia/references/specimen-v1.schema.json`, `plugins/homologia/tests/test_compare.py`, `plugins/homologia/tests/test_render.py`, `plugins/homologia/tests/test_verify.py`, the completed `plugins/homologia/examples/wad-interest-v0/` manifest, vectors, expected answers, mirror, verdict, specimens and report, the seeded-divergence example beside it, and `plugins/homologia/docs/decisions/ADR-004-exact-by-default.md`.
**Tests.** Positive fixtures cover exact agreement, declared-tolerance agreement with the echo visible, a divergence with its specimen, and weakest-class stamping across mixed provenance. Negative fixtures cover a tolerance applied without declaration, provenance classes averaged, a verdict edited to claim correctness, a specimen omitted from a divergent set, a report number absent from the verdict, and one mutation of each bound identity in `verify`. Expected minimum: 22 new cases.
**Disciplines.** phylax: the verdict and report are derived output surfaces and must not expose host paths or invent evidence. ephoros: `verify` emits the recomputed digests and one final status. metron: none, rendering makes no speed claim. elenchus: each mutation and each strengthening is a red-to-green verification guard. hypomnema: ADR-004 fixes exact-by-default with tolerance as a declared weakening.
